# INT8-v2 262K FP8 smoke — 2026-09-07

The imported native profile was exercised against
`/data/models/Qwen3.8-27B-W8A8-INT8-Agentic-v2` with vLLM 0.27.1, TP2, FP8 KV,
262,144 maximum context, prefix caching, chunked prefill, and one sequence.

The source preset's 3 GiB KV reservation did not admit the v2 artifact: vLLM
reported 4.16 GiB required for a 262,144-token request. A 4.5 GiB-per-GPU
reservation admitted 283,236 KV tokens and left both GPUs with approximately
1.9 GiB free after model and cache allocation.

The deterministic two-request smoke passed with identical arithmetic output and
the expected model alias. A fresh 250,057-token prompt passed the retrieval
probe in 248.5 seconds and returned all three embedded needles. The container
was stopped cleanly and both GPUs returned to 1 MiB used / 0% utilization.
